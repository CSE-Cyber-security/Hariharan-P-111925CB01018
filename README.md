# Hariharan-P-111925CB01018
Simple C Calculator
A command-line basic calculator written in C that performs addition, subtraction, multiplication, and division.
Features
 * Supports four basic arithmetic operations: +, -, *, /
 * Handles division-by-zero errors gracefully
 * Formats output to two decimal places
Prerequisites
You need a C compiler installed on your system (such as GCC, Clang, or MSVC).
How to Compile and Run
 * Save the program code into a file named calculator.c.
 * Open your terminal or command prompt and navigate to the directory containing the file.
 * Compile the program using GCC:
   gcc calculator.c -o calculator

 * Run the executable:
   * Linux / macOS:
     ./calculator

   * Windows:
     calculator.exe

Example Usage
Enter an operator (+, -, *, /): +
Enter two numbers: 15.5 4.5
15.50 + 4.50 = 20.00
